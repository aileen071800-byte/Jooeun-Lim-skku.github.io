# 🗺️ MZ세대 팝업스토어 & 문화 공간 소비 트렌드 지도

## 실행 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 앱 실행
```bash
streamlit run app.py
```

브라우저에서 자동으로 `http://localhost:8501` 열림

---

## 주요 기능

| 탭 | 내용 |
|---|---|
| 🗺️ 인터랙티브 지도 | Folium 기반 서울 팝업스토어 분포 지도 (히트맵 + 클릭 팝업) |
| 📊 트렌드 분석 | 월별 추이, 카테고리 버블차트, 기간-방문자 상관관계 |
| 📍 지역별 분석 | 지역별 비교 바차트, 레이더 차트, 트리맵 |
| 🏆 팝업스토어 랭킹 | 방문자/인스타/만족도/MZ비율 기준 정렬 랭킹 |

## 사이드바 필터
- 카테고리 (패션, 뷰티, 음악·엔터, 캐릭터·IP, F&B, 테크)
- 지역 (성수동, 홍대, 강남, 여의도, 한남동 등)
- 최소 방문자 수
- MZ 비율 최소값
- 입장료 유형
- 지도 스타일 / 마커 크기 기준
